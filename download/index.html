Before you open it

The installers are not code-signed yet, so your system may warn you the first time you open Quire. That is expected for now, and the files come straight from the release page above.

  • Windows. SmartScreen may say “Windows protected your PC.” Choose More info, then Run anyway.
  • macOS. The first open may be blocked. Open System Settings, go to Privacy & Security, and choose Open Anyway.
  • Linux. AppImage files need to be made executable first: right-click, Properties, Permissions, Allow executing. Or run chmod +x on it. The .deb and .rpm files install like any other package.

Use it in a browser, or install it as an app

Quire also runs in any modern browser, and it works offline once the page has loaded. You do not need to install anything to start writing.

  • Chrome or Edge. Choose Install as app above, or use the install icon in the address bar.
  • Safari on iPhone or iPad. Tap the Share button, then Add to Home Screen.
  • Android. Open the browser menu and choose Install app or Add to Home screen.
